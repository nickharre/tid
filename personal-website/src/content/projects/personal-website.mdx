# Personal Website

The site you're on right now. Not a template. Not a theme. Built from zero with a single question: what would a personal site look like if you treated it like a product worth caring about?

## Why This Exists

Most personal sites are forgettable. Same layouts, same fonts, same "hero section with gradient background." I wanted something that made people stop scrolling. Something that demonstrated craft without explaining it.

## Highlights

- **Custom GLSL water shader** with multi-layer caustics, Fresnel rim lighting, and mouse-reactive ripples
- **Bioluminescent particle system** using instanced meshes for performance at scale
- **Single continuous descent** experience. No nav bar. You dive.
- **Progressive depth gradient** that gets darker as you scroll. The metaphor is the interface.
- **Zero JS by default**. Only the 3D island hydrates. Everything else is static HTML.

## Tech Stack

- Astro (static-first, island architecture)
- React Three Fiber (declarative 3D)
- Custom GLSL shaders (not a library preset)
- Tailwind CSS (utility-first styling)
- Vercel (edge deployment)

## What I Learned

The hardest part wasn't the 3D. It was restraint. Knowing when an animation serves the experience and when it's just showing off. Every effect here exists because it reinforces the metaphor, not because it's technically impressive.
